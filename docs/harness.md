# 하네스: 완료 조건 · 시험 페이지 · 누락 사례

기능이 "됐다"고 말하기 위한 기준과 그 근거를 이 파일에 모은다.

## 1단계 완료 조건

- [ ] 현재 페이지에서 확장 프로그램을 실행할 수 있다.
- [ ] 화면의 주요 내용과 일반적인 입력값·선택값이 항목명과 함께 추출된다. (시험 페이지 통과, 실제 화면 확인 전)
- [ ] 추출 결과를 저장 전에 확인하고, 항목을 제외할 수 있다.
- [ ] 원문을 유지한 마크다운 파일을 다운로드할 수 있다.
- [x] 비밀번호·인증번호 칸의 값은 읽지 않는다. (시험 페이지 검사)
- [x] 시험 페이지의 자동 검사가 통과한다.
- [ ] 인크루트 지원서 한 화면에서 원본과 대조해 누락 여부를 확인한다.

## 1단계 범위에서 하지 않는 것

- 여러 화면으로 나뉜 단계형 지원서
- 첨부파일 내용 저장 (파일 이름만 기록)
- 다른 출처의 iframe 안 내용
